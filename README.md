
# SECURELAB — Secure Operating Systems

**Course:** CS5101 — Secure Operating Systems

**Project:** Hands-On Secure Operating Systems

## Project Overview

SECURELAB is a hands-on Linux security project focused on understanding operating system protection mechanisms through practical experiments.

The project follows the learning cycle:

**Question → Observe → Experiment → Connect → Secure → Verify**

## Project Objectives

- Investigate Linux security mechanisms.
- Understand process isolation and memory protection.
- Explore access control and privilege management.
- Examine concurrency vulnerabilities and secure IPC.
- Investigate memory safety and application sandboxing.
- Perform Linux system hardening.
- Conduct a final security assessment.

## Team

Four-member project team.

## Working Guidelines

1. Every mission must include working implementation or experiment commands.
2. Record predictions and actual observations.
3. Store relevant terminal outputs and screenshots.
4. Explain the security concepts demonstrated.
5. Verify security controls through experiments.
6. Commit completed work to the shared repository.

## Safety

All experiments must be performed inside our own Linux VM or another environment explicitly authorized by the instructor.

No unauthorized systems will be tested.
